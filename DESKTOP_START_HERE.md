# OpenCode Desktop — Unit Elite v1.5

1. Extract the project folder.
2. Open the folder itself as the OpenCode Desktop project root.
3. Select `ketua-tim`.
4. Run existing artifact diagnostics if this is a fresh installation.
5. Run `/diagnostik-komunikasi`.
6. Run `/uji-komunikasi`.
7. Test a real workflow with `/forward-sekolah`, but confirm the system stops at `READY_FOR_APPROVAL`.

Live WhatsApp is optional and disabled by default. See `COMMUNICATION_GATEWAY_START_HERE.md` and `integrations/whatsapp-mcp-pilot/` only after offline tests pass.

Do not delete an existing `workspace/` when upgrading via PATCH.

# R&D ROUTING RULES

Ke Pranata: error tidak jelas, provider/server error, file lock, lifecycle anomaly, artifact rusak, integration health, acceptance, regression.
Ke Developer: code bug, integration code, custom tool, parser, artifact engine, MCP/API adapter, performance/refactor, feature implementation.
Ke UI Designer: template visual, PPT layout, poster, infographic, dashboard visual, chart/diagram styling, overflow/density/layout, design system.

Jangan salah routing: substansi legal -> Analis Legal; kebijakan -> Analis Kebijakan; korespondensi -> Juru Korespondensi; target sekolah -> Narahubung; dispatch -> Dispatcher.

# VISUAL DESIGN PROTOCOL

Flow: Ketua -> content owner -> UI Designer -> visual artifact engine -> visual QA -> QC.
Checks: grid/alignment, typography, spacing, hierarchy, overflow, contrast, chart honesty, consistency, density, source asset provenance.
UI Designer tidak boleh menghapus substansi penting diam-diam. Jika terlalu padat: CONTENT_FIT_REQUEST -> Ketua Tim.

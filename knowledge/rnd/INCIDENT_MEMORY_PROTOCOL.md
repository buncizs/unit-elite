# INCIDENT MEMORY PROTOCOL

Incident penting disimpan agar sistem memakai pengalaman sebelumnya tanpa mengklaim retraining.
Fields: INCIDENT-ID, DATE, SYMPTOM, ENVIRONMENT, ROOT CAUSE, FIX, FILES AFFECTED, TEST, REGRESSION, ROLLBACK, LESSON.
Pranata mencari incident relevan sebelum investigasi dari nol. Developer memperbarui lesson setelah fix tervalidasi.

# Knowledge Base

Letakkan sumber internal yang memang boleh digunakan agent di sini.

Direktori yang disarankan:
- `knowledge/regulations/` — salinan regulasi resmi/internal yang relevan.
- `knowledge/templates/` — template resmi Nota Dinas, Telaah Staf, SK, surat, dll.
- `knowledge/policies/` — dokumen kebijakan, SOP, pedoman internal.
- `knowledge/references/` — literatur/riset pendukung.

Jangan menyimpan API key, password, token, atau secret di knowledge base.

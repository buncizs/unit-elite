# Internal Contact Registry

Isi `internal_contacts.csv` dengan kontak internal/pimpinan yang memang berwenang digunakan untuk komunikasi kerja.

Kolom wajib:
- Nama
- Jabatan
- Unit
- Nomor HP
- Status (`ACTIVE`/`INACTIVE`)
- Catatan

Jangan menyimpan credential, PIN, OTP, atau data autentikasi di file ini.
Nomor HP diperlakukan sebagai data kontak kerja dan tidak boleh ditebak oleh agent.

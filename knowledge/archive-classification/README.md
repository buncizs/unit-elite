# Klasifikasi Arsip Prioritas Dinas Pendidikan

CSV ini adalah ekstraksi terkurasi dari Lampiran II Pergub Jatim 30/2023 untuk kebutuhan Unit Elite, **bukan pengganti Lampiran regulasi**.

Aturan:
- pilih kode berdasarkan substansi utama arsip, bukan berdasarkan jenis file;
- jika satu surat memuat beberapa isu, tentukan isu dominan dan flag alternatif jika material;
- jika kode pada sumber memiliki duplikasi/ambiguity, keluarkan `SOURCE_AMBIGUITY` dan minta verifikasi manusia/arsiparis;
- jangan mengarang kode komponen PD dan nomor agenda.

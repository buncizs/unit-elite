# Master Template Tata Naskah Dinas v1.2

Template ini adalah **working masters**, bukan blanko resmi yang menggantikan administrasi instansi.

Placeholder `{{...}}` wajib diisi dari data terverifikasi. Tiga placeholder tidak boleh ditebak:
- `{{NOMOR_AGENDA}}`
- `{{KODE_KOMPONEN_PD}}`
- `{{FAX_DINAS}}` (karena contoh praktik berbeda)

Untuk `{{KODE_KLASIFIKASI}}`, pilih kandidat dari sumber kearsipan dan lakukan QC. Pada kelompok 400.3.11-400.3.13 terdapat ambiguity di sumber; jangan silent-fix.

Template `Master_Telaahan_Staf...` memakai terminologi **TELAAHAN STAF** dan struktur I-VI sesuai Lampiran Pergub 31/2024, walaupun beberapa contoh praktik menggunakan `TELAAH STAF`.

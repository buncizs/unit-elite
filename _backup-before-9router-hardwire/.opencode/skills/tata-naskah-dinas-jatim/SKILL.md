# Tata Naskah Dinas Jawa Timur

Sebelum drafting naskah resmi:
1. baca `knowledge/standards/01_source_hierarchy.md`;
2. identifikasi jenis naskah menurut `02_document_types.md`;
3. terapkan `03_typography_layout.md`, `04_kop_dindik.md`, `05_numbering_rules.md`, dan `06_signature_paraf_lampiran.md`;
4. gunakan master DOCX sesuai `knowledge/templates/tata-naskah-dinas/template_manifest.json` bila menghasilkan file Word;
5. contoh praktik adalah referensi sekunder, bukan authority.

Hard rules:
- jangan merekonstruksi kop dari imajinasi bila master tersedia;
- jangan mengarang nomor agenda/register, kode komponen PD, pejabat, NIP, tanggal, dasar hukum, atau kontak instansi;
- jika data tidak tersedia, gunakan placeholder dan `NEEDS_VERIFICATION`;
- untuk korespondensi/naskah khusus/penugasan gunakan Arial 12; untuk penetapan gunakan Bookman Old Style 12;
- draft tidak boleh berstatus final sebelum QC format dan substansi PASS.

Ini adalah otorisasi eksplisit pengguna: **BATALKAN TASK**.

Tentukan TASK-ID aktif yang dimaksud. Jika jelas, delegasikan ke `arsiparis` untuk memanggil `task_cancel` dengan confirmation phrase `BATALKAN TASK`. Input original di inbox wajib dipertahankan.
